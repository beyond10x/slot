# O6 — Self-improvement, built into all of it

Every component records what it did; the system proposes, lands and re-measures its own
improvements. Cross-cutting: it is a property of O1–O5, not a seventh component.

| | |
|---|---|
| how slot serves it | every build records queue wait, run time, CPU seconds and peak memory in the job log, so contention between agent sessions is measured instead of guessed, and a change to slot sizes is re-measured against the same log (`AGENTS.md` § Serves) |
