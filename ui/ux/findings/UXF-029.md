In the Finished table the failed state is a red number among zeros; the word "failed" is on the
page only in a hover text. The Queue's heading says "waiting for slots" also when a job waits for
disk space or memory (review-queue-call-mode.png).

One-line fix: one word per state ("not on slot"; "failed (101)", "ok", "cancelled" in an "exit"
or "result" column), and "live" only for a stream that carries output.

Fix (R-11), three parts: the Finished table has a "result" column with "ok", "failed (101)" and
"cancelled"; the header and the Sessions heading say "not on slot" like the chart and the badge; the Queue
heading names what the listed jobs wait for ("waiting for disk space and memory"). Not changed: the
meanings of "live", and the result as the pane and the timeline's hover text word it.
