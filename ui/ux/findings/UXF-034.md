# UXF-034: A session without a title has its id in the session column and none in the id column

- id: UXF-034
- title: A session without a title has its id in the session column and none in the id column
- class: copy
- severity: S3
- metric: none (one row of the Sessions table)
- status: closed
- found_by: review of the screenshots after the polish that followed R-11
- evidence_recording: none (hermetic replay busy-failed at 1366x768)
- evidence_screenshot: none kept in the repository
- evidence_lines: the Sessions table shows "9e8d7c6b" under "session" and an empty cell under "id" for the session without a title; every other row has a title and 8 digits
- regression_asset: ux/findings.spec.ts "UXF-034 busy-failed: every row of the Sessions table shows its id, and a session without a title says so" and src/lib/host.test.ts "the Sessions table names the id in every row, and says when a session has no title"
- scenarios: every scenario whose census has a session without a title
- cost: S

The id moved between two columns depending on whether the session had a title, so the id column
could not be read down.

One-line fix: the id in the id column of every row, and "no title" in the quiet colour as the name.

Fix (second polish pass after R-11): `sessionCells` (src/lib/host.ts) gives the name ("no title"
for a session without one, "(no session)" for processes without a session id) and the first 8
digits of the id. The id column shows at every width; before, it was dropped below 900 px. The job
tables still name such a session by its 8 digits, since they have no id column.
