The user knows an agent by its session title. To see which jobs are that agent's, the id behind a
title has to be read from a hover title in the Sessions table and then matched against hex digits
further down the page. No task of this round needs it, because each card names the job number.

One-line fix: show the session title (cut, with the id as the full value) in the job tables.
