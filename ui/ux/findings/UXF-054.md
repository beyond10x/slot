# UXF-054: An empty queue leaves the endpoint panel empty

- id: UXF-054
- title: An empty queue leaves the endpoint panel empty
- class: layout
- severity: S3
- metric: none (content of the endpoint panel)
- status: closed
- found_by: an independent review of the live view with a build node
- evidence_recording: none (hermetic replay cluster-queue-empty at 1366x768)
- evidence_screenshot: none kept in the repository
- evidence_lines: a box of about 260x380 px said only "Queue empty"; with no queue it carried no number at all
- regression_asset: ux/findings.spec.ts "UXF-054 cluster-queue-empty: with no job queued the endpoint panel says where the jobs run"
- scenarios: cluster-queue-empty
- cost: S

Fix: with nothing queued the panel says where the jobs run: one entry per node with its name, its
running jobs and its busy slots (from `api/nodes`), then the slots free over all nodes. The queue
list is a list only while it has jobs, so an empty one is no list without items.
