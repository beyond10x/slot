The Running table opens the unit row of the three jobs that use the most cores now. Cores change
every second, so the set changes with a tick and every row below a changed one moves by 30 px
while the user reads or aims at a row. A row the user toggled keeps its state; the others do not.

One-line fix: open a unit row only on the user's toggle, or keep a row open once it was opened.

Fix (R-11): a unit row opens and closes only by its toggle; no row is open by default. No earlier
finding or task depended on rows opening by themselves (UXF-013 names the toggle, which stays).
