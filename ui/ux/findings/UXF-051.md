Fix: the header tile reads "slots in use on this host"; the Cores chart "used on this host"; the
lower chart "Cores in use on this host"; "Share of the pool on this host", which says that the jobs
of build nodes are not counted. The Running line splits the jobs: "6 jobs: 4 on build-node-eu-1d,
2 on this host use 2.4 cores" (the cores are measured only here). Finished now holds the node's
jobs the daemon lists: `splitJobs` keeps the 60 that ended last instead of the 60 highest ids, and
the heading says "newest first, on this host and its build nodes".
